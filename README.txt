DBI2 Phase 2 Collaboration Network

Files:
- index.html: page
- network.css: styling
- network.js: interactive network logic
- projects.js: project data generated from the supplied Excel file

Publishing:
Upload all four web files into the same directory on the DBI2 web server, for example /phase2-network/. Then open index.html through the web server URL.

The page has no external JavaScript dependencies and should work on a standard static web server.
